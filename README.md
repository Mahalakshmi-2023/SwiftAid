# SwiftAid: Real-Time Ambulance Tracking System
SwiftAid is a smart ambulance tracking system that shows real-time location, finds the fastest route, and alerts hospitals and families during emergencies. It uses Google Maps, GraphHopper for routing, Firebase for live updates, and Twilio for sending alerts.

## Features
1. Real-Time Ambulance Tracking
2. Optimized Routing with GraphHopper
3. Nearest Hospital Detection
4. SMS & Email Notifications (Twilio, Firebase)
5. Responsive UI (React.js, Tailwind CSS)

### Setup and Installation

1. Clone the repository
2. Install dependencies(Frontend and Backend)
3. Set environment variables in `.env` files for Firebase, Twilio, Google Maps, and GraphHopper.
4. Run the app:
   (i)Frontend: [npm start](http://localhost:3000).
   (ii)Backend: [npm start](http://localhost:5000).
